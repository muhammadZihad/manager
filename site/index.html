What it does

A supervisor, not a tab bar

The sidebar is organised around what you're working on — not around anonymous shells you have to recognise by their scrollback.

One click

Start the whole project

Mark items auto-start and one button spawns every one of them, each with its own working directory and environment. Stop All tears the project down again.

Real PTYs

Interactive, not piped

xterm.js over genuine pseudo-terminals, so prompts, colours, TUIs and live resize behave exactly as they do in your own terminal. Agents like claude are just another session.

Visible

Ports and resources per session

The listening port appears on the row. CPU, memory and child-process count for the selected session sit in the footer — summed across the whole process tree, not just the process that was spawned.

Import

It already knows your scripts

Point it at a directory and it reads package.json scripts — picking npm, yarn or pnpm from your lockfile — and Makefile targets. Tick the ones you want.

Background

Closing the window doesn't stop work

The window hides to a tray icon showing a live session count. Quitting while something runs asks first, then kills the full process tree — so no orphan is left holding port 3000.

Shareable

Config that lives with the repo

Optionally keep a project's setup in its own folder so it can be committed. Machine-specific paths are deliberately left out, so it's useful to whoever clones next.

Yours

Themes, fonts, and keys you choose

Dark, light or system. Eight terminal colour profiles with a live preview. Every shortcut rebindable — and chords the shell needs, like ⌘K, are refused rather than silently stolen.

Internals

The awkward parts, done properly

Most "run my scripts" tools pipe stdout and lose everything interesting. These are the details that decide whether a process supervisor is trustworthy.

  • A session is a tree, not a process. php artisan serve forks the real server; the port belongs to the child. Signals and metrics target the process group, so stopping actually stops it.
  • Blocking reads stay off the async runtime. Each session owns a dedicated OS thread reading its PTY, and a second thread reaps the child for a real exit code.
  • Two-phase spawn. The backend hands over a session id, the UI attaches its listeners, and only then does output start flowing — so nothing from a fast starter is lost.
  • Nothing outlives the app. Every session is killed on quit, with a backstop on the exit path that a plain confirmation dialog would miss.
  • Rust and a system WebView. Tauri 2, so the binary is single-digit megabytes rather than a bundled browser per app.

Install

Two ways in

Download a build

macOS ships a .dmg. Windows currently ships a portable .zip.

Go to releases

Unsigned builds. Gatekeeper and SmartScreen will warn on first launch — on macOS, right-click the app and choose Open to allow it once. Signing, notarisation and a real Windows installer are on the roadmap.

Build from source

Node 18+, a stable Rust toolchain, and your platform's Tauri prerequisites.

$ git clone https://github.com/muhammadZihad/manager.git $ cd manager $ npm install $ npm run tauri dev
