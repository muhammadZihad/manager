Features

Everything a project needs, in one place

Define it once. Start it forever.

One-click startup

Mark items auto-start and one button spawns them all — dev server, watcher, API, agent — each in its own PTY and working directory.

Real terminals

xterm.js over genuine PTYs. Interactive prompts, colours, TUIs and live resize all behave exactly as they do in your own terminal.

Project-shaped sidebar

Projects expand into Commands, Agents and Terminals — with running badges, status dots, search, and the active session highlighted inline.

Import your scripts

Detects package.json scripts (respecting your lockfile's package manager) and Makefile targets. Tick the ones you want.

Lives in your tray

Closing the window hides it — processes keep running. The tray shows a live session count, and quitting mid-build asks first.

Yours to tune

Dark, light or system theme. Pick a default shell from the ones actually installed. Set terminal font, size and scrollback.

Export & share

Send a project — or all of them — to a JSON file. Import merges rather than overwrites, so team setups travel safely.

Debuggable by design

File-based logging on both the Rust and React sides, plus an error boundary — so a bad day produces evidence, not a blank window.

Genuinely native

Rust + Tauri with the system WebView. A single-digit-megabyte binary instead of a bundled browser per app.

Under the hood

Real PTYs, not piped stdout

Most "run my scripts" tools pipe stdout and lose everything interesting. Manager allocates a genuine pseudo-terminal per session, so programs behave exactly as they do in your shell.

  • Dedicated reader thread per session — PTY reads block, so they never touch the async runtime.
  • Two-phase spawn — listeners attach before output flows, so nothing from fast starters is lost.
  • Reaper thread per child — real exit codes, reported inline and in the sidebar.
  • Nothing orphaned — every session is killed on quit, so no stray processes survive.

Install

Get it running

Download a build, or compile from source in three commands.

Download a build

Grab the latest from the releases page. macOS ships a .dmg; Windows currently ships a portable .zip.

Go to Releases
Unsigned builds. Gatekeeper and SmartScreen will warn on first launch. On macOS, right-click the app → Open to allow it once. Signing and notarisation are on the roadmap, as is a proper Windows installer.

Build from source

Needs Node 18+, a stable Rust toolchain, and your platform's Tauri prerequisites.

$ git clone https://github.com/muhammadZihad/manager.git $ cd manager $ npm install $ npm run tauri dev
